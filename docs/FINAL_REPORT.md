# FlyChat 最终报告 — 果蝇脑混合对话系统（三阶段集成交付）

**日期**: 2026-10-04
**代码**: `flybrain/`（仿真器）· `flychat/`（对话接口与训练）· `viewer/`（3D 查看器与实时模式）
**一句话总结**: 把 MaleCNS v1.0 果蝇全脑连接组（164,587 神经元 / 25,563,197 有向突触）
作为真实的脉冲动力学引擎接入文本对话回路：文本注入全脑、逐 token 增量仿真、从果蝇脑
状态读出回复。读出层测试困惑度 **6.84**（果蝇脑状态），比等参数量随机向量基线 **9.58**
改善 **28.6%**。本报告验证的是**通路**——生物仿真与人工解码的端到端闭环——而非对话能力。

---

## 1. 架构：混合路线，哪些是生物真实的、哪些是人工的

```
用户文本
   │  ① [人工] 字符 tokenizer（54 字符）
   ▼
   │  ② [人工] 编码器：可训练嵌入 (54×64) + 固定随机投影
   │      → 嗅觉群 2,639 / 视觉群 4,109 感觉神经元电流 (5–16 mV)
   ▼
   ┌─────────────────────────────────────────────┐
   ║  ③ [生物真实] MaleCNS v1.0 全图 LIF 仿真器     ║
   ║     每 token 16 ms 子窗，164,587 神经元          ║
   ║     25.56M 有向突触（ACh 兴奋 / GABA·Glu·His 抑制）║
   ║     KC→MBON 多巴胺门控可塑性（61,210 条可塑边）   ║
   └─────────────────────────────────────────────┘
   │  ④ [生物真实] 状态读出：[嗅觉 2,639 | 视觉 4,109 | DN 1,314] 放电率，8,062 维
   ▼
   │  ⑤ [人工] 读出 GPT：4 层 × d=128 × 4 头，1.87M 参数，因果注意力
   ▼
生成的 token → 回注全脑（③）→ 循环，直到回合分隔符 '\n'
```

**生物真实的部分**（完全来自解剖与动力学数据，无训练）：

- **连接组**：MaleCNS v1.0 traced-only 子图，突触计数直接来自连接组；递质符号按
  `consensus_nt` 注释（ACh 兴奋，GABA/谷氨酸/组胺抑制）。
- **脉冲动力学**：DOOMFLY 的 LIF 参数集（0.1 ms 步长、不应期、自适应、0.275 mV/突触）。
- **可塑性**：多巴胺门控的 KC→MBON 突触抑郁（资格痕迹 τ = 1 s，392 个 DAN），
  即果蝇蘑菇体嗅觉学习回路的经典第一步。
- **信息通路**：文本电流注入感觉神经元 → 全脑传播 → 下行神经元读出。神经元的
  "角色"（感觉/中枢/下行）全部来自真实标注。

**人工的部分**（承担语言建模，无任何生物学对应）：

- 字符 tokenizer、编码器嵌入（保持随机初始化，见 §6）、感觉群分配的随机投影、
  读出 GPT 的全部参数、采样温度与 top-k 截断。
- 文本↔神经活动的**映射本身**是任意的：字符刺激"嗅觉/视觉"群是工程选择，
  没有生物学意义；全脑在任意 token 序列下的响应分布也与自然刺激的统计不同。

## 2. 仿真器验证（阶段一）

验证实验（`flybrain/validate.py`，结果 `results/validation_results.json`）：

| 检验 | 结果 | 结论 |
|---|---|---|
| 静息状态（无驱动 2 s） | 0 个尖峰 | 网络静息完全静默 |
| 刺激后持续活动 | ~29 万尖峰/bin 稳定不衰减（≥10 s），13,334 神经元持续活跃 | w_scale=0.275 下为有界持续震荡吸引子；episode 间必须 `reset(keep_memory=True)` |
| 刺激传播 | 120,865 神经元被激活（8.4%），按 superclass 分布与解剖预期一致（cb_intrinsic 主导） | 活动真实传播至全脑而非局部 |
| 权重尺度扫描 | 0.275 不衰减；0.15×基线（≈0.041）撤刺激后归零 | 标定了超/亚临界两档工作点 |
| 差异条件反射（CS+/CS−, DAN 配对） | 配对气味 A（CS+）的 MBON 响应 154 → 31 尖峰（−80%），气味 B（CS−）保持 102 → 102 不变；不配对对照中 A 仅 154 → 75（−51%） | 多巴胺门控可塑性**特异**于时间配对的 CS，符合果蝇嗅觉回避学习范式 |

## 3. 对话训练：四条件对照（阶段二）

数据：DailyDialog 13,117 段对话 → 字符级（词表 54），train 1,142 episodes /
142,902 token，test 114 / 14,491 token。四条件使用**完全相同的数据、架构、种子与
训练预算**，仅状态输入不同（详见 `TRAINING_REPORT.md`）：

| 条件 | 状态输入 | 测试困惑度 | 相对 brain |
|---|---|---|---|
| **brain** | 真实果蝇脑状态轨迹 | **6.84**（best val 6.44） | — |
| shuffled | 真实状态时间打乱 | 8.73 | +27.6% |
| random | 等参数量 iid 随机向量 | 9.58 | +40.1% |
| none | 状态置零（纯 token LM） | 8.68 | +26.9% |

三个对照给出一致的结论：

1. **brain 比等参数量随机向量好 28.6%**（6.84 vs 9.58）——增益不是维度或参数量带来的；
2. **shuffled ≈ none**（8.73 vs 8.68）——打乱时间结构后增益几乎消失，说明增益来自
   果蝇动力学的 **token 对齐信息**，而非状态向量的边缘统计；
3. **random 略差于 none**（9.58 vs 8.68）——随机状态只是噪声，模型正确地学会忽略它。

状态可解码性（留一最近邻 token 身份解码，随机水平 1.9%）：全状态 **94.7%**，
仅 DN 段 7.8%，时间打乱 7.8%——状态确实逐 token 编码了输入身份信息。

## 4. 多巴胺可塑性效应

**回路层面**（阶段一，§2 末行）：配对 CS 的 MBON 响应下降显著大于未配对 CS 与
不配对对照，可塑性是刺激特异、时间依赖的。

**接口层面**（阶段二 `eval_dopamine.py`）：固定 token 刺激（CS）× DAN 14 mV（US）
配对 3×200 ms：

| 指标 | 配对（learning=True） | 可塑性关闭 |
|---|---|---|
| KC→MBON 权重变化 | 29,493 / 61,210 条边，均值 0.98×，最低 0.58× | 0 条 |
| DN 群体放电率 | 8.61 → 8.22 Hz | 8.61 → 8.38 Hz |
| 可塑性特异状态变化 L2 | **349**（嗅觉 280 / DN 204 / 视觉 40） | — |

多巴胺配对特异地改变了全脑状态（尤其 KC→MBON→DN 通路下游；不受可塑突触支配的
视觉感觉群几乎不变，与解剖预期一致）。但注意：**训练时读出 GPT 只见过固定权重下
的状态**，故这一效应尚未转化为对话行为的可测量改变——目前是回路层面的验证，
不是行为层面的学习。

## 5. 对话入口（阶段三交付）

Web 单页聊天 + 3D 实时模式（使用方法详见 `USAGE.md`）：

- `python server.py`（flychat/，端口 8910）：聊天服务，POST `/api/chat` 一轮对话，
  GET `/api/activity` 返回最近 16 ms 子窗的全脑放电率快照；
- `python3 serve.py`（viewer/，端口 8900）：`live.html` 实时模式每 0.5 s 轮询，
  按放电率高亮活跃神经元（164,587 个脑神经元全部与 viewer bodyId 对齐成功）；
- `chat_cli.py`：命令行客户端。

全流程程序化验证（`validate_web.py`，7/7 通过，`validation_result.json`）：
状态接口、聊天页面、生成回复非空、活动数据非空（3,000 个活跃神经元，按放电率
排序）、多轮上下文注入、live.html 可访问、reset。

典型一轮：上下文 26 token + 生成 68 token，21 s（每个 token 16 ms 全脑仿真，
约 0.3 s/token 墙钟）。

## 6. 诚实的局限性

1. **验证的是通路，不是对话能力。** 生成呈"词形但无语义"
   （如 `i has i apeull orne can fora sure...`）——1.87M 参数读出头在 14 万字符
   语料上的预期水平。本项目的结论是"文本→全脑仿真→状态读出"的闭环在工程上
   端到端可行且信息可解码，**不能**声称任何对话质量。
2. **绝对困惑度受语料与模型规模限制。** 6.84 的困惑度来自极小词表（54 字符）与
   小语料的字符级预测；它只在四条件间可比，不能与大模型指标比较。
3. **编码器未训练。** 脉冲脑不可微，编码器保持随机初始化（仅训练了读出层）。
   状态可解码（94.7%）说明随机编码 + 果蝇动力学已经携带信息，但远非最优。
4. **文本↔神经活动的映射是任意的。** 字符电流注入"嗅觉/视觉"群没有生物学依据；
   全脑对这种非自然刺激的响应是否落在生物可行的活动流形内未验证。
5. **多巴胺效应止步于回路层面**（§4），没有闭环到对话行为。
6. **持续震荡吸引子**（w_scale=0.275 的固有性质）使活动水平偏离静息生物状态；
   每轮必须重置动力学。LIF 无噪声、递质符号粗粒化、可塑性规则未拟合行为数据
   （见 `flybrain/README.md` §5）。

### 后续方向

- 经脑响应代理模型对编码器做直通估计微调，或用 REINFORCE 直接优化编码器；
- 扩大语料与状态收集算力（每 token 16 ms 仿真是硬瓶颈，4 小时收集 1,142 episode）；
- 把多巴胺通道接入对话回路（如以用户反馈当奖惩信号），检验可塑性能否转化为行为改变；
- 读出群体加入 MBON / 中央脑内源性神经元，或改用突触电导 g。
